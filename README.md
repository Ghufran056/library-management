# 📚 Library Management System (CLI)

A simple **Command Line Interface (CLI)** Library Management System built with Python. This project allows users to manage a collection of books while demonstrating **file handling** for persistent data storage.

## ✨ Features

- 📖 Add new books
- 📚 View all books
- 🔍 Search books by title or author
- ✏️ Update book information
- 🗑️ Delete books from the library
- 💾 Save and load library data using file handling
- 🖥️ Easy-to-use terminal interface

## 🛠️ Built With

- Python
- File Handling (Text/JSON)

   ```bash

   ```

2. Navigate to the project folder:
   ```bash
   cd library-management
   ```

3. Run the application:
   ```bash
   python main.py
   ```
